# Skill: trace-requirement

## Procedure

1. Identify the claim or AC ID.
2. Find or create a control statement under the legal workstream owned units (e.g. `compliance/controls/<id>.md`).
3. Record: control ID, source citation, implementing artifact path, residual risk.
4. Legal-validator fails the workstream if any in-scope claim lacks a control link.
