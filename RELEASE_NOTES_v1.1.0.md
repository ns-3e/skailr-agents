# skailr-agents v1.1.0

Two-tier multi-agent prompt pack for Claude Code and Cursor.

## Install

```bash
git clone https://github.com/YOUR_ORG/skailr-agents.git
cd skailr-agents
./install.sh /path/to/your-project
```

## Highlights

- Program tier (`/discover`, `/plan-program`, `/build-program`) + workstream tier (`/ship-feature`, `/build-feature`)
- Agent channels message board with orchestrator router
- Cursor mirror generated from authoritative `.claude/` tree
- Content team as reference domain implementation
