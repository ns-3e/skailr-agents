# skailr-agents — Deep Audit (2026-08-02)

Baseline: commit `d3f4317`. Method: full read of `.claude/**`, `.cursor/**`, `scripts/**`,
`docs/**`, `examples/**`, installers, CI; every validator executed against the repo and
against synthetic edge-case fixtures; `remirror.sh` executed on a pristine copy and diffed.

Severity: **P0** blocker · **P1** correctness · **P2** efficiency · **P3** polish.
Each finding cites file:line at the audit baseline. Items marked **[FIXED]** were
remediated in the commit series that accompanies this audit; the rest are tracked in
`IMPROVEMENT-BACKLOG.md`.

## Phase 0 — System model (as reconstructed from the repo)

Four tiers, each with its own state root and resume reader:

| Tier | Root | State file | Resume reader |
|---|---|---|---|
| Portfolio | `.claude/portfolio/` | `plan.md`, `ledger.md` | `/status-portfolio` |
| Program | `.claude/program/` | `ledger.md` (gates, phases A–E, per-feature cursors, contract versions, blockers) | `ledger-status.mjs` ← `/continue-program` |
| Feature | `$ARTIFACT_ROOT` = `.claude/tmp/` (standalone) or `.claude/program/workstreams/<ws>/features/<slug>/` (nested via skill `run-feature-queue`) | `progress.md`, `board.md` + `tickets/` | `feature-status.mjs`, `ticket-status.mjs` ← `/continue-feature` |
| Brownfield | `.claude/repo/` | `orientation.md`, `ownership.json`, `map-report.md` | `/map-repo` resume |

- Build-writes ↔ resume-reads are **format-consistent** at every tier. The weakness found
  is path *parameterization*, not format (F-10).
- Progressive disclosure is real: registry (125 lines) → lead → workers; a backend-only
  `/yolo` loads no domain-team material (measured, Phase 3).
- Human gates: story, spec, plan approval, map-repo confirm, expert promotion. YOLO
  auto-decides those and logs `type: decision`; script gates are unconditional in every
  command file (verified — no mode-conditional script gate exists).
- Mirror: `remirror.sh` regenerates `.cursor/rules|commands`, root `CLAUDE.md`,
  `.cursor/model-routing.md`, `manifest.json`. Executed on a pristine copy: **zero diff**
  against the committed tree. The only hand-maintained mirror file is `.cursor/README.md`
  (by design). Skills are deliberately not mirrored.

## Phase 1 — Consistency & integrity findings

### P0

**F-1 [FIXED] `check-intair-seam.mjs` fails on the shipped repo.**
`node scripts/skailr/check-intair-seam.mjs` → exit 1:
`AC-8: .claude/commands/map-repo.md mentions Intair` and the same for
`mint-expert.md`. The AC-8 scan (`check-intair-seam.mjs:291-294`) forbids *any*
`intair` mention in `.claude/commands/**`, but 1.6.0 deliberately wired optional,
deliberate-invocation Intair steps into `/map-repo` (Phase 5) and `/mint-expert`
(optional step) via skill `call-intair`. The validator was never updated and is not in
CI, so it rotted. Fix: AC-8 now permits command references that explicitly route through
skill `call-intair`; the blanket ban still applies to everything else.

**F-2 [FIXED] Version tripwire: 1.6.0 vs 1.7.0.**
`package.json:4` = `1.6.0`; `manifest.json:4` = `1.7.0`; `scripts/remirror.sh:329`
hardcodes `"version": "1.7.0"`; CHANGELOG's latest cut is `[1.6.0] — 2026-07-29` with a
populated `[Unreleased]` above — no 1.7.0 entry exists. CHANGELOG.md:44 states the
invariant that all three move together. Because remirror re-stamps the manifest from its
own constant, the drift can never self-heal. Fix: remirror now reads the version from
`package.json` (single source); package.json bumped to 1.7.0 to match the already-shipped
manifest; CHANGELOG `[1.7.0]` cut from the existing Unreleased content.

### P1

**F-3 [FIXED] `validate-channels.mjs` inbox never forgets contract-changes.**
`validate-channels.mjs:76-82` counts a message as inbox if `type === "contract-change"`
or addressed `@human` — *regardless of status*. Resolved escalations stay in the inbox
forever. Because the shipped `program.md` seeds a worked example containing two resolved
contract-change messages, **every fresh install reports `inbox=2`** phantom items, and
`--strict-inbox` (exit 2 on non-empty inbox) would hard-fail permanently after the first
contract-change in any real program. Repro: `node scripts/skailr/validate-channels.mjs`
on a fresh checkout. Fix: `resolved`/`answered` messages leave the inbox regardless of
type/addressee.

**F-4 [FIXED] Malformed channel messages become invisible, silently.**
`MSG_RE` (`validate-channels.mjs:9-10`) requires the exact
`### MSG-n\n<headers>\n---\n<body>` shape. A message missing the `---` separator parses
as zero messages and the file **passes** (`OK: 0 message(s)`). An agent that slightly
malforms a `@human` blocker makes it invisible to both routing and validation — the
worst possible failure mode for an escalation channel. Repro: fixture with
`### MSG-001` and no `---` → exit 0. Fix: the validator now compares raw `### MSG-`
heading count against parsed count and fails on mismatch.

**F-5 [FIXED] `check-ownership.mjs` gate can pass by failing.**
(a) `check-ownership.mjs:138` interpolates `--base`/`map.baseRef` unquoted into
`execSync("git diff --name-only " + base)` — a ref with spaces/metachars breaks or
injects (repro: `--base "HEAD --extra"` leaks `--extra` into git). (b) If both git
invocations throw, `paths = []` and the script prints `OK: ownership map valid; 0
path(s) checked`, exit 0 — the gate silently passes exactly when it could not observe
the diff. Fix: `execFileSync` argument-vector invocation; when the diff cannot be
obtained at all the script now exits 1 (fail closed) instead of reporting success.

**F-6 [FIXED] Glob dialect blindness in ownership/overlap checks.**
The hand-rolled `minimatch` in `check-ownership.mjs:12-31` and `ticket-status.mjs`
supports only `**` suffixes and single-segment `*`. Brace/`?`/char-class globs are
treated as literals: two tickets owning `src/{api,core}/**` and `src/api/**` validate as
non-overlapping (repro: synthetic 2-ticket board → `OK: 2 tickets, DAG valid`), and a
real diff path under `src/api/` matches neither, surfacing later as spurious `unowned`.
Silent misinterpretation of an ownership expression is worse than rejection. Fix: both
scripts now reject globs containing `{`, `?`, or `[` with an explicit
`unsupported glob syntax` error (fail closed; the supported dialect is documented in the
error).

**F-7 [FIXED] `check-contracts.mjs` status enum bypassed by `|`.**
`check-contracts.mjs:66-73`: any status containing `|` skips strict validation ("allow
template" carve-out) — but templates live in `schemas/`, which this script never scans.
Repro: contract with `status: totally|bogus` → `OK: 1 contract(s) checked`. Fix: the
carve-out is removed; status must be one of `draft|frozen|superseded`.

**F-8 [FIXED] `install.ps1` drift vs `install.sh`.**
(a) `$PackagedCommands` (`install.ps1:130-134`) omits `mint-expert` — Windows installs
never receive `.cursor/commands/mint-expert.md` (install.sh copies it, `install.sh:155`).
(b) install.ps1 appends `!.claude/program/schemas/**` (`install.ps1:203`) which
install.sh does not. (c) install.ps1 lacks install.sh's roster-fingerprint FATAL guard
(`install.sh:211-236`) protecting `.claude/experts/` on upgrade — tracked as backlog
B-4 (needs a Windows environment to verify; not fixed blind here).

**F-9 CHANGELOG describes a three-pass validator; the shipped validator has four.**
`CHANGELOG.md:17` ("three named passes … no check category was dropped") vs
`validator.md:75` (**Pass 4 — UX Quality**) and `.cursor/rules/validator.mdc:45` ("four
passes"). **[FIXED]** — wording corrected in the 1.7.0 cut.

**F-10 [FIXED] Nested-run path hardcoding (six coordinated defects).**
Every command declares `$ARTIFACT_ROOT` discipline, then violates it at specific call
sites. Standalone runs are unaffected; every *nested* program feature
(`workstreams/<ws>/features/<slug>/`) hits all six:

| # | Defect | Sites |
|---|---|---|
| a | `check-ownership.mjs --from-spec .claude/tmp/spec.md` hardcoded | `yolo.md:115,139`, `build-feature.md:67`, `continue-feature.md:62` |
| b | `feature-status.mjs --json` with no `--progress`/`--root` | `yolo.md:49`, `build-feature.md:40`, `continue-feature.md:37`, `ship-feature.md:39` |
| c | Expert artifacts pinned to `.claude/tmp/expert-*.md` while consumers read `$ARTIFACT_ROOT/expert-*.md` (`architect.md:23`, `story-writer.md:23`, `validator.md:21`) — files diverge *and collide across parallel features* | `expert.md:65,89,117`, `build-feature.md:83`, `yolo.md:98,110,153`, `ship-feature.md:71,92` |
| d | `request.md`/`mode.md` written to `.claude/tmp/` unconditionally vs `feature-progress.template.md:7` (`request: <ARTIFACT_ROOT>/request.md`) | `yolo.md:59`, `ship-feature.md:45` |
| e | Nested feature channels (`$ARTIFACT_ROOT/channels/`) never validated — skill `route-channels` documents only `--dir .claude/program/channels` and `--tmp` (hardcoded `.claude/tmp/channels`, `validate-channels.mjs:29`) | `route-channels/SKILL.md:17-19` |
| f | Skill `check-ownership` documents no nested `--map` form though `run-ticket-board` writes `$ARTIFACT_ROOT/ownership.json` | `check-ownership/SKILL.md:18-20` |

Fix: all call sites parameterized on `$ARTIFACT_ROOT`; `expert` role writes
`$ARTIFACT_ROOT/expert-*.md` (Task prompt passes the root, default `.claude/tmp`);
skills gained the nested invocation forms.

**F-11 Domain-team agents have no `$ARTIFACT_ROOT` handling (inverse defect).**
All content/design/finance/legal/marketing/pm agents hardcode
`.claude/program/workstreams/<ws>/…` (e.g. `content-lead.md:72`) and carry zero
`ARTIFACT_ROOT` references (grep-verified). A domain team dispatched outside a program
has no standalone fallback. Lower urgency than F-10 (domain teams are only routed by
`/build-program` today). **Backlog B-6** — bring the six team roots under the same
parameterization as engineering.

### P2

**F-12 Silent exit-0 no-ops across validators (12 catalogued).**
Worst offenders: `emit-stubs.mjs:69-79` silently emits nothing for `.md`-only contracts
(repro: contract without sidecar → `OK: emitted 0 stub(s)`, exit 0 — the launch-kit
example's five contracts would all be skipped without a word); `feature-status.mjs:68`
exits 0 when `ticket-status.mjs` is missing; missing-dir skips in `check-contracts:50`,
`check-ownership:109`, `validate-channels:61`, `check-experts:660` (the last is correct
by design — fresh installs must not fail). Individually defensible, collectively they
mean "all gates green" cannot be distinguished from "no gates ran". **Backlog B-1
(`doctor.mjs`)** is the systemic answer; emit-stubs now names skipped contracts
**[FIXED]** as part of the F-1..F-7 script pass.

**F-13 `archive-program.mjs` treats "no ledger" as `complete=true`.**
`archive-program.mjs:217-221` (deliberate: "safety net for next-start"). A killed
pre-freeze run (ledger is only seeded at contract freeze) is archived without `--force`,
with dry-run reporting `complete=true`. Nothing is destroyed (archive, not delete), so
P2 not P1 — but the label is a lie and the behavior is undocumented. **Backlog B-7**:
report `leftovers (no ledger)` instead of `complete=true` and document the rule in
`archive-program-state`.

**F-14 CI gaps.** `.github/workflows/ci.yml` never runs: remirror freshness (mirror
could drift undetected), `check-experts.mjs`, `check-intair-seam.mjs` (why F-1 rotted),
version consistency (why F-2 rotted), `install.ps1` (why F-8 rotted). **[FIXED]** for
seam + version + remirror-freshness + check-experts; installer-array parity check is
backlog B-5.

**F-15 Installer copy arrays are a third source of truth.**
`install.sh:139-155` and `install.ps1` hardcode `PACKAGED_RULES`/`PACKAGED_COMMANDS`
independent of remirror's generated set and of `manifest.json`. Adding an agent/command
requires three hand-syncs; CI smoke-checks only a fixed subset. **Backlog B-5**: derive
installer lists from `manifest.json`.

## Phase 3 — Token economics

Measured at baseline:

- **Total agent prompt mass:** 31,527 words (~41k tokens) across 40 files — but this is
  *never* co-loaded; each Task loads exactly one role file.
- **Minimal backend-only `/yolo`:** command + 8 engineering roles + documenter + 3 skills
  ≈ 14.6k words (~19k tokens) *spread over ~10 sequential dispatches* (≈1.4–2.5k tokens
  of definition per dispatch). **Zero domain-team, portfolio, legal, finance, marketing,
  design or content material loads.** Progressive disclosure holds as designed.
- **Duplication is a maintenance surface, not a runtime cost:** 11 near-verbatim blocks
  (tone ×40 @119w, task-return ×40, artifact-root ×8, channels ×8+~24 variant,
  handoff ×3, cleanup ×3, prime-directive doubled per file). Runtime overhead ≈3–8% per
  dispatch; the real risk is edit-one-forget-39 drift. Recommendation is therefore
  **not** extraction (Claude Code has no include mechanism; generating `.claude/` would
  invert the source-of-truth invariant) but a **byte-identity lint** (backlog B-2) that
  fails CI when canonical blocks diverge, plus per-agent tightening where words don't
  change behavior (B-12: `researcher` 234 lines and `expert` 202 lines are the outliers).
- **Prime-directive doubling** (§2 + §4 verbatim in most files) is the one pure waste:
  ~40–60 words × 40 files with zero behavioral value — folded into B-12.
- **Redundant round trips:** none found structurally. The `matched: none` skip rule
  prevents empty expert consults; commands consistently pass artifact *paths*, not
  bodies ("do not paste the full story"), and CI greps enforce two of those phrases.
- **Gate cost:** all script gates are sub-second node invocations; ordering is already
  fail-fast (ownership before channels before tests). No batching win worth complexity.
